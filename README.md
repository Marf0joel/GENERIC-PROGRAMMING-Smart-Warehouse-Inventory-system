# Smart Warehouse Inventory System

## Description

This repository contains two Python programs that demonstrate the concept of Generic Programming using Python type hints.

### Activity 1 - Trial Storage System
A generic Storage[T] class that stores and retrieves a single item of any data type.

### Activity 2 - Warehouse Inventory System
A generic Inventory[T] class capable of storing and retrieving items while displaying each item's type and value. The class is extended to manage multiple items while maintaining generic type consistency.

## Concepts Used

- Generic Programming
- Type Variables
- Classes and Objects
- Methods
- Lists
- Python Type Hints
